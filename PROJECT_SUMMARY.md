## 🚀 Getting Started

### Quick Installation:
```bash
# 1. Install dependencies
npm install
cd client && npm install && cd ..

# 2. Start development server
npm run dev

# 3. Access the application
# Frontend: http://localhost:3000
# Backend: http://localhost:5000
```

### First-Time Setup:
1. **Register**: Create your account (first user becomes admin)
2. **Create Project**: Set up your first repository
3. **Add Files**: Use the built-in code editor
4. **Track Issues**: Create and manage project issues
5. **Install on Android**: Add to home screen for native app experience
